# Dorwin Analysis and Hardin Version

A **Dorwin Analysis** identifies prose patterns that lack substantive meaning — filler,
hedging language, repetition, vague promises, unsupported claims, and appeals to authority.

## Hardin Version

The analysis produces a **Hardin Version**: a compact operational restatement that preserves
every concrete obligation, decision, constraint, and testable fact, while eliminating padding
and non-committal phrasing.

## Application

Works best for time-pressured or iterative documents — requirements and design notes where
accumulated discussion has created unnecessary verbosity. The original prose stays in place
unless Brian explicitly asks for it to be replaced.

## How It Works

Ask for a "Dorwin Analysis" of specific content. The response delivers a compressed Hardin
Version alongside the original, extracting only the actionable, measurable, and verifiable
elements.
